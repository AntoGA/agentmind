# Упаковка agentmind — 26 ноября 2026

## Изменения

- Единый источник метаданных и зависимостей: `pyproject.toml`, сборка PEP 517 через setuptools. `setup.py` оставлен как совместимый вход без дублирования метаданных.
- Базовые зависимости: NumPy, Pydantic, Tenacity. Extras `openai`, `sentence-transformers`, `dev`; удалены зависимости неработающих хранилищ и неиспользуемые библиотеки.
- Минимальный Python повышен с 3.9 до 3.10, в соответствии с проверяемой матрицей 3.10/3.12. Версия пакета сохранена: 0.2.0, публикации нет.
- Удалены фиктивный email, PyPI badge и неподтверждённая команда установки одноимённого пакета из индекса. Указаны экспериментальный статус и установка из проверенного checkout.
- `Memory(embeddings=provider)` позволяет работать без SDK/API, используя объект с `encode(text)`. По умолчанию остаётся OpenAI: нужен extra и ключ. Ошибка отсутствующего SDK содержит команду установки extra.
- README: корректный `db_path`, требования провайдеров и команды сборки. LangChain остаётся экспериментальным и не входит в проверенный контракт; extra для него не объявляется.
- CI собирает sdist и wheel из sdist, проверяет их через twine, устанавливает wheel в отдельное окружение и запускает копию тестов вне checkout с `python -I`. Артефакты сборки и JUnit сохраняются.

## Локальная проверка

Python 3.12, чистые окружения сборки и установки:

1. `python -m build` — успешно; wheel построен из sdist.
2. `python -m twine check dist/*` — оба артефакта PASSED.
3. Установка `dist/*.whl pytest` в отдельный venv — успешно.
4. Импорт с `-I` указывает на `site-packages/agentmind`, а не исходники.
5. `python -I -m pytest -q tests` из отдельного каталога — **21 passed**.
6. Wheel содержит только пакеты agentmind и dist-info, включая MIT LICENSE; tests/examples не попали в пакет.

Новые проверки: версия и минимальный Python в метаданных, состав базовых зависимостей, SQLite roundtrip с переданным провайдером, понятная ошибка при недоступном OpenAI SDK.
